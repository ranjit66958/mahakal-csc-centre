GitHub પર અપલોડ કરવાની રીત

1. ZIP Extract કરો.
2. ranjit66958/mahakal-csc-centre repository ખોલો.
3. Add file > Upload files પસંદ કરો.
4. index.html, style.css, script.js અને owner-photo.jpeg ને repository ના મુખ્ય ફોલ્ડરમાં અપલોડ કરો.
5. Commit changes કરો.
6. થોડી મિનિટ પછી વેબસાઇટ ખોલીને Ctrl+F5 દબાવો.

ફોટો મૂળ સ્વરૂપમાં જ રાખ્યો છે. મોબાઇલમાં ફોટો ઉપર અને લખાણ નીચે દેખાશે.
